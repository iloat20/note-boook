# 2026-05-29 架构重构日志

## 本次重构内容

### 1. 新建 errors.js — 统一错误类型
- `AppError` 基类 + `ValidationError` / `NotFoundError` / `NetworkError` / `CalculationError` 子类
- 替换项目中散落的 `Error` 和字符串错误码

### 2. 新建 dateRange.js — 集中日期范围计算
- `today()` / `thisWeek()` / `thisMonth()` / `yearToDate()` / `fullYear(year)` / `getByPeriod(period)`
- 消除 statsService.js 和 stats.js 中重复的日期范围计算逻辑

### 3. 修复 entityFactory.js — var → const
- 模块级 3 个 `let` → `const`，1 个 `var dateStr` → `const`

### 4. 重构 statsService.js — 提取内部辅助函数
- 提取 `buildStockIdMaps()` / `calcWeightedDividendYield()` / `calcRangePnL()` / `buildStockMarketMap()`
- `getMonthAndYearStats()` 和 `getPeriodStatsWithReturn()` 复用上述函数
- 移除未使用的导出：`calcXIRRForRange`、`getTotalXIRR`
- 文件大小：587 行 → ~370 行

### 5. 新增 getAnnualReportData() — 统一年报计算逻辑
- 将 `stats.js` `onOpenAnnualReport` 中 ~130 行内联计算移到 `statsService.js`
- `onOpenAnnualReport` 简化为 10 行：调用 `getAnnualReportData()` + `setData`
- 复用 `calcRangePnL()`、`getClearedPositions()`、`getPositionSummary()` 等服务层函数

### 6. 简化 stats.js
- 移除 `getRates`/`getRate` 导入（不再需要）
- `onOpenAnnualReport` 从 130 行 → 10 行
- 文件整体更简洁，职责更清晰

## 架构原则
- **服务层集中计算**：所有数据计算逻辑在 `statsService.js`，页面只做展示
- **内部函数复用**：`calcRangePnL()` 被 `getMonthAndYearStats()`、`getPeriodStatsWithReturn()`、`getAnnualReportData()` 三个函数复用
- **日期计算统一**：所有日期范围通过 `dateRange.js` 获取
- **错误处理统一**：通过 `errors.js` 的错误类型体系

## 测试结果
- 本次修改文件全部通过 Lint
- 测试无新增失败（2 个预先存在的失败与本次无关）
