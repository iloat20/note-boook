# 液态滑动器 + 高级动效 + 图表增强 Spec

## Why
当前股票交易记录小程序的 UI 设计已具备 Minimal + Spatial 风格基础，但交互动效和图表展现可以进一步提升，引入液态滑动器、Z轴视差、液态消融等前沿微交互来提升用户体验的精致度。

## What Changes
- 市场切换从下划线 Tab 改为**液态滑动器**（跑马灯式平滑过渡滑块）
- 费率**实时自动计算**并展示明细，无需手动点击"重算"
- 持仓卡片添加**Z轴视差滚动**效果
- 删除操作使用**液态消融动效**
- 统计页添加**交易热力图**（按日期展示交易密度）
- 图表 X 轴从第一笔交易开始（保持现有逻辑），Y 轴根据数据范围自适应
- 优化图表渲染：红涨绿跌柱状图 + 渐变连线累计收益图

## Impact
- Affected specs: minimal-spatial-redesign（增强，非破坏）
- Affected code: app.wxss, pages/index/*, pages/record/*, pages/history/*, pages/stats/*, utils/feeCalculator.js

## ADDED Requirements

### Requirement 1: 液态市场滑动器
系统 SHALL 在首页和流水页提供液态滑动器替代原有下划线 Tab。滑动器为跑马灯式渐变色滑块，背景透明，选中项平滑过渡到带渐变色的胶囊形状。

#### Scenario: 切换市场时液态滑动器平滑过渡
- **WHEN** 用户点击市场 Tab（全部/A股/港股/美股）
- **THEN** 亮色胶囊滑块以 300ms cubic-bezier(0.4, 0, 0.2, 1) 滑动到目标位置
- **AND** 滑块背景为 var(--color-accent) 轻微渐变

### Requirement 2: 费率实时自动计算
系统 SHALL 在记录页用户输入价格或数量后，实时自动计算手续费并填入，同时展示费率明细。用户可手动覆盖，但继续修改价格/数量时仍会重新计算。

#### Scenario: 输入价格后自动计算费率
- **WHEN** 用户在买入/卖出记录页输入价格和数量
- **THEN** 系统根据市场类型自动计算手续费（A股/港股/美股使用各自费率标准）
- **AND** 手续费明细列表实时更新显示
- **THEN** 当用户修改价格或数量时，手续费实时重新计算
- **AND** 用户可手动覆盖手续费值

### Requirement 3: 卡片 Z 轴视差滚动
系统 SHALL 在首页持仓列表滚动时为每张卡片提供 Z 轴视差效果。视差通过 translateZ 和 perspective 实现，卡片在滚动时有轻微的空间层次感。

#### Scenario: 滚动持仓列表时卡片产生视差
- **WHEN** 用户上下滚动持仓列表
- **THEN** 当前可见区域的卡片产生微妙的 Z 轴深度偏移
- **AND** 中间卡片略微"浮起"，上下卡片略微"退后"
- **AND** 动效使用 CSS transform: perspective + translateZ，无 JS 计算

### Requirement 4: 液态消融删除动效
系统 SHALL 在删除交易/分红记录时展示液态消融动效。长按或点击删除后，卡片如液体般收缩消融。

#### Scenario: 删除记录时液态消融
- **WHEN** 用户确认删除一笔交易或分红记录
- **THEN** 该记录卡片触发液态消融动效
- **AND** 动效包含：scale(0.8) + opacity(0) + filter: blur(4px)，持续 400ms
- **AND** 下方卡片平滑上移填补空位（300ms ease-out）

### Requirement 5: 交易热力图
系统 SHALL 在统计页新增交易热力图模块。热力图以日历格子形式展示，用颜色深浅表示每日交易活跃度（交易次数/金额）。

#### Scenario: 查看交易热力图
- **WHEN** 用户进入统计页
- **THEN** 在盈亏趋势图下方显示交易热力图
- **AND** 每个格子代表一天，颜色从浅灰（无交易）到深蓝/橙色（高频交易）
- **AND** 格子尺寸 14px × 14px，间距 2px
- **AND** 热力图按月份分组显示，支持左右滑动切换月份

### Requirement 6: 红涨绿跌柱状图 + 渐变累计收益线
系统 SHALL 优化统计页图表渲染。柱状图使用红涨绿跌配色，累计收益折线使用渐变色彩连线。

#### Scenario: 图表渲染
- **WHEN** 用户查看盈亏趋势图
- **THEN** 正值柱子为红色(#FF3B30)，负值柱子为绿色(#34C759)
- **AND** 累计收益图的数据点之间用渐变色连线连接
- **AND** 最高点和最低点标注数值
