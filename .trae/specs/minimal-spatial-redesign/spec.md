# Minimal + Spatial UI 设计重构 Spec

## Why
当前股票交易记录小程序的 UI 设计采用传统金融风格卡片布局，视觉效果较为常规。需要将所有页面重构为 Minimal + Spatial UI 设计语言，参考微信读书的设计风格，打造极简、高冷、高效的视觉体验。

## What Changes
- **BREAKING** 全面重构全局样式系统 (app.wxss)
- **BREAKING** 重构所有页面 WXSS 样式
- 重构所有页面 WXML 结构，适配新设计
- 更新 app.json 导航栏配置
- 实现自定义 TabBar
- 底部安全区适配
- 胶囊按钮避让
- Dark mode 跟随系统

## Impact
- Affected specs: 全部页面
- Affected code: app.wxss, app.json, app.js, 所有 pages/*.wxml, pages/*.wxss, pages/*.js

## 设计规格

### 风格定义
- **设计语言**: Minimal + Spatial UI，参考微信读书
- **核心原则**: 大面积留白、无边框、阴影层级、微透明层叠
- **内容区占比**: 屏幕宽度的 60%（左右各 20% 留白）

### 色彩体系
| 用途 | 色值 | 说明 |
|------|------|------|
| 主体白 | #FFFFFF | 卡片、内容区背景 |
| 浅灰 | #F5F5F7 | 页面背景 |
| 深灰 | #1D1D1F | 标题文字 |
| 正文灰 | #6E6E73 | 正文文字 |
| 辅助灰 | #86868B | 辅助信息 |
| 分隔灰 | #E5E5EA | 弱分隔线 |
| 强调色 | #FF6B35 | 仅用于 CTA 按钮 |
| 盈利红 | #FF3B30 | 盈利用红色 |
| 亏损绿 | #34C759 | 亏损用绿色 |
| A股蓝 | #007AFF | 市场标签 |
| 港股橙 | #FF9500 | 市场标签 |
| 美股紫 | #AF52DE | 市场标签 |

### 阴影层级
| 层级 | 值 | 用途 |
|------|------|------|
| shadow-sm | 0 1px 3px rgba(0,0,0,0.04) | 轻微浮起 |
| shadow-md | 0 4px 12px rgba(0,0,0,0.06) | 卡片 |
| shadow-lg | 0 8px 30px rgba(0,0,0,0.08) | 弹层/重点卡片 |

### 排版
| 层级 | 字号/字重 | 字间距 | 用途 |
|------|-----------|--------|------|
| Display | 28px / 700 | 0.02em | 页面大标题 |
| Title | 20px / 600 | 0.02em | 模块标题 |
| Body | 15px / 400 | -0.01em | 正文 |
| Caption | 12px / 400 | 0 | 辅助文字 |

### 圆角
- 卡片: 16px
- 按钮: 12px
- 标签: 6px
- 输入框: 10px

### 间距
- 页面边距: 20px
- 模块间距: 16px
- 卡片内边距: 20px
- 列表项间距: 12px
- 元素内间距: 8px

### 交互
- 页面转场: opacity 0→1 + translateY(8px→0), 200ms ease-out
- 按钮点击: opacity 0.7, 即时反馈
- 无 hover 缩放、无弹性动画
- 列表项左滑删除（微信 swiper 组件）

### 微信适配
- 底部安全区: padding-bottom 适配 env(safe-area-inset-bottom)
- 胶囊按钮避让: 顶部留出导航栏高度
- TabBar: 自定义组件，图标 81×81px
- 所有触摸目标 ≥ 44px

## 页面结构

### 1. 首页 - 持仓 (pages/index/index)
- 顶部: 大标题"持仓"
- 市场筛选 Tab（无背景色，仅文字 + 底部指示线）
- 持仓卡片列表: 白底 + shadow-md + 16px 圆角
- 每张卡片: 市场标签 + 股票代码名称 + 持仓量/成本/现价 + 盈亏
- FAB 按钮: 右下角 56px 圆形，强调色 #FF6B35

### 2. 流水页 (pages/history/history)
- 顶部: 大标题"流水"
- 类型筛选: 买入/卖出/分红 Tab
- 市场筛选: 横向滚动 chips
- 记录列表: 按日期分组，日期分隔线
- 每条记录: 市场标签 + 代码名称 + 类型标签 + 金额
- 支持左滑编辑/删除

### 3. 统计页 (pages/stats/stats)
- 顶部: 大标题"统计"
- 三个指标卡片: 累计投入 / 累计回收 / 总盈亏
- 时间筛选: 周/月/年 Tab
- 盈亏趋势: 柱状图
- 累计收益: 折线图
- 统计明细列表

### 4. 记录页 (pages/record/record)
- 顶部: 标题 + 返回按钮
- 表单: 市场选择 / 股票代码 / 名称 / 方向 / 价格 / 数量 / 手续费 / 日期时间 / 备注
- 底部: 提交按钮（CTA 强调色）

### 5. 分红页 (pages/dividend/dividend)
- 顶部: 标题 + 返回按钮
- 表单: 股票选择 / 每股金额 / 数量 / 日期 / 备注
- 底部: 提交按钮（CTA 强调色）

### 6. 详情页 (pages/detail/detail)
- 顶部: 股票名称 + 返回按钮
- 股票信息: 市场标签 + 代码 + 名称
- 持仓信息卡片
- 盈亏统计卡片
- 交易记录列表
- 分红记录列表
