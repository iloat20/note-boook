合并为一个双 Y 轴组合图：
- 左 Y 轴：当期盈亏（柱状图，红绿配色）
- 右 Y 轴：累计收益（折线 + 圆点，橙色）
- 共用 X 轴（周/月/年）

   const parts = n.toFixed(2).split('.')

**P1 修复：**
4. `getNextId()` 重写为自增计数器：
   ```js
   let _idCounter = null
   function getNextId() {
     if (_idCounter === null) _idCounter = wx.getStorageSync('_id_counter') || 0
     _idCounter++
     wx.setStorageSync('_id_counter', _idCounter)
     return _idCounter
   }
   ```
   三处调用点（`Stock.create` / `Transaction.create` / `Dividend.create`）同步去掉 `key` 参数。
5. `markDataDirty()` — 空 catch 改为 `console.warn('[markDataDirty]', e)`
6. 抽取公共函数 `calcStatsForRange(transactions, dividends, startDate, endDate, label)`，`getPeriodStatsList` 四个 case 内部均改为一行调用

**P2 修复：**
7. `getPositionSummary` 排序加除零保护：
   ```js
   const aRatio = a.avgCost > 0 && a.quantity > 0 ? a.floatingPnL / (a.avgCost * a.quantity) : 0
   ```
8. `getAllPositionsWithRealizedPnL` 浮点比较改为 `Math.abs(x) > 0.01`
