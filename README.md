# 茄子笔记本

微信小程序 · 资产记账小工具

纯客户端的微信小程序，用于记录各类资产的记录流水，追踪持有成本与浮动收益，生成统计图表与年度报告。所有数据 `wx.setStorageSync` 本地存储，无需云端。

## 项目说明

### 功能

- **资产看板** — 首页汇总总资产、持有成本、浮动收益，左滑可编辑 / 转出 / 删除
- **记录流水** — 转入 / 转出记录，按月份折叠分组，编辑半屏面板，批量删除
- **统计概览** — 资产变动 / 记录次数 / 期末资产 / 记录天数全局卡片，完整明细，已结束资产
- **年度报告** — 纯 CSS 渲染的年度收益、月度可视化、策略分布
- **数据备份** — JSON 导入 / 导出（合并或覆盖模式）
- **Markdown 导出** — 一键生成记录流水 Markdown 文件并分享
- **快捷记录** — 首页浮层快速录入交易，实时校验价格与费用估算

### 架构

```
├── pages/              # 主包页面（资产 / 流水 / 统计）
├── packageDetail/      # 分包 — 资产详情
├── packageRecord/      # 分包 — 新增 / 编辑交易
├── components/         # 通用组件（年度报告、快捷记录、滑动选择器等）
├── custom-tab-bar/     # 自定义 Tab Bar（SVG 图标 + 毛玻璃样式）
├── styles/             # 全局样式变量

├── utils/
│   ├── storageCore/    # 底层存储（LRU 缓存 + Object.freeze 防篡改）
│   ├── models/         # Active Record 模型（资产 / 交易 / 其他收益 …）
│   ├── services/       # 业务服务（价格、统计、持有计算）
│   ├── helpers/        # 纯函数（持有计算、费用、排序、日期范围）
│   ├── state/          # 轻量状态管理（脏标记 + mutation 订阅）
│   ├── cache/          # LRU 缓存管理器（按资产粒度清除）
│   ├── ui/             # 页面 mixin、触摸手势、动画助手
│   └── constants/      # 枚举常量、配置
├── api/                # 网络请求层
└── tests/              # Jest 单元测试
```

### 数据流

```
用户操作 → 页面调用 Model.save()
   → upsertAndSave() + wx.setStorageSync 持久化
   → markDataDirty() 按资产粒度清除 LRU 缓存
   → 返回上一页 → onShow() 消费脏标记 → 增量刷新
```

### 技术特色

- **纯客户端** — 所有数据本地存储，0 服务端依赖
- **LRU 缓存** — 持有 / 价格 / 统计 / 周期数据分层缓存，按资产粒度清除，TTL 自动过期
- **计算缓存** — computedCache 自动追踪依赖，数据未变时跳过重算
- **CSS 优先** — 年度报告纯 CSS 渲染，无需 Canvas，GPU 加速
- **毛玻璃设计** — iOS 风格设计系统，CSS 自定义属性，`backdrop-filter` 导航栏
- **手势驱动** — RAF 节流 + data path 精确更新的左滑菜单
- **延迟加载** — 分包预加载、按需组件、非首屏模块延迟 import
- **入场动画** — CSS `transform/opacity` 交错入场，首次展示后锁定，不重播
- **日期索引** — dateIndex 按时间桶预索引交易，范围查询 O(1) 定位

## 使用说明

### 1. 添加一笔交易

- 在首页点右下角「+」进入完整记录页，或直接使用首页的「快速添加」浮层。
- 填写**资产代码 / 名称**、选择**方向**（转入 / 转出）、**数量**、**价格**、**费用**。
- 代码支持自动识别格式（纯数字、带 HK 前缀、纯字母等），无需手动选择市场。
- 确认后点「确认添加」即可。

### 2. 查看资产看板

- 首页「资产」页汇总**总资产（元）**、资产变动、变动幅度与资产数量。
- 列表展示每类资产的持有数量（份）、成本、当前价值与浮动变动，左滑可编辑 / 转出 / 删除。

### 3. 查看记录流水

- 「流水」页按月份分组展示所有转入 / 转出记录。
- 顶部可按类型筛选（全部 / 转入 / 转出），点击单条记录可编辑或删除。

### 4. 查看统计与年度报告

- 「统计」页展示资产变动、记录次数、期末资产、记录天数全局卡片，完整明细与已结束资产。
- 年度报告以图表形式呈现年度收益与策略分布，可分享或导出。

### 5. 备份与导出

- 在统计页可通过 JSON 导入 / 导出备份数据（合并或覆盖模式）。
- 支持一键导出 Markdown 记录流水文件，分享给好友或自行留存。

### 6. 分享资产截图

- 首页点右上角分享按钮，自动生成资产看板截图，可保存到相册或转发给朋友。
