## 一、微信后台需你手动操作

### 1. 服务类目（最关键）
改成**非金融类目**，不要挂在 `金融 / 证券 / 股票 / 股评` 下：

- 推荐：`工具` → `记账`
- 备选：`效率` → `备忘录 / 记事`
- 这两个类目**不需要证券投资咨询资质**，是个人记账类小程序的常规选择。

### 2. 类目介绍 / 功能描述（直接复制，不要出现股票/行情/股评/持仓/盈亏/买入/卖出/分红/证券/A股/港股/美股）

```
茄子笔记本是一款纯本地的个人资产记账小工具。用户可记录各类资产的购入与售出、当前价值与持有数量，自动统计资产总值、收益与增长情况，并生成可视化的统计图表与年度报告。所有数据仅保存在本机，不涉及任何行情咨询、交易撮合或投资建议。
```

### 3. 小程序简介

```
纯本地个人资产记账工具：记录资产增减与当前价值，自动统计收益与增长，生成图表与年度报告。数据不上传云端。
```

### 4. 隐私协议 / 用户隐私保护指引
（如未部署隐私协议，需先放一个静态页并填写网址）

- 本小程序不收集任何个人信息；
- 所有记账数据仅存储在用户本机（`wx.setStorageSync`），不上传任何服务器；
- 不向任何第三方共享数据。

## 三、残余风险与退路

- **实时价格抓取仍在**：应用保留「自动获取当前价值」功能（拉取公开价格数据）。若人工审核在实机试用时发现实时行情抓取，仍可能被要求补充资质。
- **若再次被拒**：最稳的退路是临时关闭自动获取价格，改为用户手动填写「当前价值」。这涉及 `utils/services/stockPrice.js` 调用开关的改造，可作为下一步处理，不影响本次文案过审尝试。
- 提交审核时，截图页尽量展示汇总/统计页（已中性化），个股名称本身中性，问题不大。
