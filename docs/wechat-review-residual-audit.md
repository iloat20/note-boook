## 🔴 A 档：运行期可见的金融敏感词（必须改）

### A1. 录入页「标签」选项全是股票术语 —— 最高频暴露点
- **数据源**：`utils/constants/index.js:40-51`（`DEFAULT_STRATEGIES`）
- **可见位置**：`packageRecord/pages/record/record.wxml:177-181`（标签多选渲染 `{{item}}`）
- **现状**：`追涨 / 抄底 / 止损 / 止盈 / 定投 / 打新 / 调仓 / 消息面 / 技术面 / 基本面`
- **风险**：用户录入选标签时一眼可见，全是股票交易/分析黑话。审核员试录一笔即触发怀疑。
- **建议**：换成中性通用标签（如 `长期 / 短期 / 观察 / 重点 / 已清仓 / 待定`）或清空改为自由输入。

> 注：之前 B 档把「策略标签」改成了「标签」（容器名中性了），但**选项内容没改**，仍暴露。

## 🔴 B 档：功能行为（实机可触发，文案改不掉）

### B1. 实时行情抓取 —— 功能层最高危
- **文件**：`utils/services/stockPrice.js`（腾讯财经 `qt.gtimg.cn`）
- **触发点**：
  - 录入页 / 快捷录入：输入代码自动拉价（`record.js:149/325/527/553`、`quick-record.js:217/340`）
  - 首页：手动「获取价格 / 刷新」按钮（`index.js:757` `onRefreshPrice`）
- **风险**：审核员在审核版实机点一下「获取价格」，即拉取真实股票行情（600000 平安银行、AAPL.OQ 苹果）——这是金融工具的铁证，任何文案都掩盖不了。
- **建议（退路 1，之前文档已记）**：临时关闭自动拉价 + 隐藏首页刷新按钮，改为手动填写「当前价值」。

## 🟡 C 档：源码注释 / 死代码（常规审核不读，深究有痕）

### C3. `pinyinIndex.js` 硬编码全量真实股票名（死代码）

- 因 `stockDatabase` 内置池已置空，这些**不运行、不展示**；但源码里全是股票名，若审核读源码必疑。
- **建议**：清空 `NAME_PINYIN_MAP`（或整个文件改为空映射）。
